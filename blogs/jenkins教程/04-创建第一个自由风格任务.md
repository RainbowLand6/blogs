# 04-创建第一个自由风格任务

自由风格任务（Freestyle project）适合认识 Jenkins 的基本流程。真实项目更推荐 Pipeline，但先做一次自由风格任务，能帮助你理解构建记录、控制台日志和工作区。

## 创建任务

1. 点击 **New Item**。
2. 名称输入 `hello-jenkins`。
3. 选择 **Freestyle project**。
4. 点击 OK。

在 **Build Steps** 中选择 **Execute shell**，输入：

```bash
echo "Hello, Jenkins!"
echo "当前目录：$(pwd)"
echo "构建编号：$BUILD_NUMBER"
```

保存后点击 **Build Now**。

## 查看结果

点击左侧构建记录中的 `#1`，再打开 **Console Output**。

若看到：

```text
Hello, Jenkins!
Finished: SUCCESS
```

就说明任务运行成功。

## 构建状态含义

| 状态 | 含义 |
| --- | --- |
| SUCCESS | 所有步骤正常结束。 |
| FAILURE | 某个步骤返回失败，例如命令退出码不是 0。 |
| UNSTABLE | 构建完成，但通常表示测试有失败。 |
| ABORTED | 被人工或超时取消。 |

## 理解环境变量

Jenkins 会自动提供一些变量：

| 变量 | 示例 |
| --- | --- |
| `BUILD_NUMBER` | `12` |
| `BUILD_URL` | 当前构建的网页地址。 |
| `WORKSPACE` | 本次构建代码所在目录。 |
| `JOB_NAME` | 任务名称。 |

在 Windows Agent 上执行命令时，构建步骤应选择 Windows batch command，变量写法也会变成 `%BUILD_NUMBER%`。

## 本章完成标志

`hello-jenkins` 任务至少成功运行一次，你能在控制台日志中找到执行过的命令和 `Finished: SUCCESS`。
