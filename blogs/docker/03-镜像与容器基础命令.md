# 镜像与容器基础命令

目标：能拉取镜像、启动容器、查看日志并安全停止容器。

## 1. 拉取和查看镜像

```bash
docker pull nginx:alpine
docker image ls
```

镜像名一般是：

```text
仓库/镜像名:标签
nginx:alpine
```

不要长期依赖 `latest`。明确写版本或稳定标签，部署结果才可重复。

## 2. 启动 Nginx 容器

```bash
docker run -d \
  --name web-demo \
  --restart unless-stopped \
  -p 8080:80 \
  nginx:alpine
```

参数说明：

| 参数 | 含义 |
|---|---|
| `-d` | 后台运行 |
| `--name` | 指定容器名 |
| `--restart unless-stopped` | Docker 重启后自动拉起，手动停止则不拉起 |
| `-p 8080:80` | 主机 8080 映射到容器 80 |

验证：

```bash
curl http://127.0.0.1:8080
docker ps
```

## 3. 查看日志和容器内部状态

```bash
docker logs web-demo
docker logs -f --tail 100 web-demo
docker exec -it web-demo sh
```

`docker exec` 用于临时排查。不要进入容器后手工修改配置并把它当成正式变更；容器重建后修改会丢失，应改镜像、挂载配置或 Compose 文件。

## 4. 停止、启动与删除

```bash
docker stop web-demo
docker start web-demo
docker restart web-demo
docker rm web-demo
```

容器正在运行时不能直接删除，先 `stop`。删除容器不会删除其镜像；挂载到卷中的数据也不会自动删除。

## 5. 常用查看命令

```bash
docker ps
docker ps -a
docker inspect web-demo
docker stats
```
